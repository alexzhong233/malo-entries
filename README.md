Token Radar — a pre-token opportunity board: 758 DeFiLlama protocols scored with one implied-value formula learned from the snapshot itself (peer TVL→mcap multiple, momentum and no-token age factors), 210 rows ranked (40 watchlist protocols covered, 170 early projects below the TVL floor), live-token protocols kept apart so a market cap is never mistaken for a forecast. Ships an interactive dark dashboard with per-row model breakdowns and 7-step costed farm plans.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
