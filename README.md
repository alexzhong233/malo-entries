A sun-soaked top-down open-world crime game. Explore six thousand acres of palm-lined streets, turquoise bay and neon nightlife, steal cars, outrun a five-star police response, and work your way through seven story jobs to pull off the Solara Score. Everything runs in one canvas with plain static files — no build step, no libraries, no network.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
node serve.ts
```

Open http://localhost:8080/game/ in Chrome.

Controls:
- **WASD** — walk / drive / steer
- **Mouse** — aim
- **Left click** — shoot
- **E** — enter or exit a car, interact with mission markers
- **F** — accept the next job when standing on its marker
- **Space** — handbrake / drift while driving
- **Shift** — accelerator boost
- **TAB** — minimap zoom
- **C** — controls overlay
- **Esc** — pause
