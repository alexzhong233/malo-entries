A chess engine in a single ≤4 KB Python file: iterative-deepening alpha-beta with quiescence search, transposition table, killer/history move ordering and piece-square evaluation, on a fixed node budget (no clock) so play is fully deterministic.

## Run it

```sh
python3 main.py
```
